# Vevor BLE Bridge Add-on Repository

Dieses Repository enthält das [Vevor BLE Bridge](https://github.com/bderleta/vevor-ble-bridge) Add-on für Home Assistant.

## Installation

1. Gehe in Home Assistant zu **Einstellungen** → **Add-ons** → **Add-on Store**
2. Klicke auf die drei Punkte in der oberen rechten Ecke und wähle **Repositories**
3. Füge die URL dieses Repositories hinzu: `https://github.com/DEIN_BENUTZERNAME/vevor-ble-bridge-addon`
4. Klicke auf **Hinzufügen**
5. Suche nach "Vevor BLE Bridge" und installiere es
